Using aggregate functions allows us to perform calculated operations on all rows that meet a certain condition (or on all rows in the table)

selet count(*) Amount_teachers , Subjects
from teachers t

Number of credits being taught.

SELECT SUM ( a . asig_cred ) Amount_Credit
FROM imparte i , asignaturas a
WHERE imp_asig = asig_cod ;

Number of credits taught by each teacher.

SELECT imp_dni , SUM ( asig_cred ) Amount_Credit
FROM imparte i
JOIN asignaturas a ON ( imp_asig = asig_cod )
GROUP BY imp_dni ;

Name of the teachers, ids and credits they teach.

SELECT prof_nombre , prof_dni , SUM ( asig_cred ) Amount_Credit
FROM imparte i
JOIN asignaturas a ON ( imp_asig = asig_cod )
JOIN profesores p ON ( imp_dni = prof_dni )
GROUP BY prof_nombre , prof_dni ;

Output ordering

 Number of credits taught by each teacher oder by "Amount_Credit"

SELECT imp_dni , SUM ( asig_cred ) Amount_Credit
FROM imparte i
JOIN asignaturas a ON ( imp_asig = asig_cod )
GROUP BY imp_dni
ORDER BY Amount_Credit ;

It's also valid "ORDER BY 2" or "ORDER BY SUM(asig_cred)"
